# Implementation triage

Use this mapping for implementation issues in the [GitHub tracker](issue-tracker.md).

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

These roles do not apply to decision tickets. A readiness label is not authorization to perform remote or consequential actions.

The configured labels must exist before they can be applied. Setup documents the mapping but does not create labels or verify remote configuration. If existing labels differ, obtain owner approval and update this mapping rather than introduce duplicates.

Changes to this mapping require owner approval.
